## 面板服還是 VPS，先搞清楚權限差在哪

面板服給你的是「已裝好的遊戲伺服器端 + 網頁控制台」，VPS 給你的是「一台空機器」。這個差別決定了後面所有事情。

面板服基於 MCSManager，買完在網頁上選遊戲類型、按啟動就完事。它的頻寬形式固定：上行 50Mbps，IP 是 NAT 映射，給你 10 個連接埠用。開泰拉瑞亞的流程大致是五步——註冊後綁微信領券、購買時選 Terraria + tShock 或原版伺服器端並挑機房、進控制台下拉到 MCSManager 面板按啟動、在啟動腳本末尾加參數、看到 `Server started` 就把 IP 和連接埠發給朋友。新手照著做大概 10 到 15 分鐘。啟動參數可以加 `-maxplayers 8` 限制人數、`-password 你的密碼` 設密碼、`-difficulty 1` 切專家模式（0 經典 / 1 專家 / 2 大師 / 3 旅程）、`-language zh-Hans` 讓伺服器端講中文。

VPS 拿到的是完整系統權限，Linux 或 Windows 隨你挑，SSH、RDP、VNC 都能連，一部機器要開幾個服就開幾個服。代價是你得自己裝 Java、上傳服務端、設防火牆規則。規格區間從 2 核 4G 10M 一路到 8 核 32G 30M。

零基礎就從面板服開始，之後熟了再換。走 VPS 這條路又不想從零折騰的話，雨雲已經有 tModLoader 的搭建教學，更新伺服器端檔案後改啟動腳本即可，全程面板操作。

## 按人數和 MOD 選配置，三檔就夠

伺服器端吃的是單核性能，MC 的主執行緒基本跑在一個核上，主頻越高 TPS 越穩，人多時越不容易卡頓掉線。泰拉瑞亞同一個邏輯：主頻比核心數重要，核心再多而主頻低，該卡還是卡。所以選配置的順序是：先看人數和 MOD 決定記憶體與核心數下限，再看這檔位配的是哪顆 CPU。

| 玩法場景 | 建議配置 | 說明 |
| --- | --- | --- |
| 2–4 人，原版或少量 MOD | 1 核 2G | 跑原版夠用，面板服最低檔就落在這裡 |
| 4–8 人，原版或中等 MOD | 2 核 4G | 多數人的落點，穩定不卡 |
| 8 人以上或 tModLoader 大型整合包 | 4 核 8G 以上 | 留餘量，模組載入不崩 |

另外泰拉瑞亞官方從 1.4.0.1 版起，伺服器預設支援最多 16 名玩家同時在線，人數上限這件事本身不用太擔心，先擔心配置撐不撐得住。

MOD 服還有一個容易被忽略的點：記憶體要留給模組載入，4G 跑大型整合包很勉強，選到 4 核 8G 以上比較保險。CPU 方面 MOD 服對單核主頻要求更高，Ryzen 系列或 i9-14900K 這類高主頻型號優先。

## 固定計費還是動態計費，差別可能比套餐還大

雨雲遊戲雲有兩種計費方式，這是我覺得最值得先弄懂的一段，因為它會讓同一台機器的月帳單差出一倍。

**固定計費**：月租固定，CPU 跑滿或空轉同價。適合 24 小時掛機、玩家隨時可能上線的中大型服，帳目清楚，不會半夜被帳單嚇到。

**動態計費**：基礎租金壓得很低，但 CPU 使用率超過 20% 的部分按「CPU 電量」日結另收。換算方式是 1 CPU 電量 ≈ 30% CPU × 1 分鐘，單價大概 0.0005 到 0.001 元，系統每天還會送一定額度的免費電量。

判斷規則很簡單：你的服一天有幾個小時真的有人在線？

晚上八點到十二點開、白天沒人，動態計費的基礎租金加幾塊錢電量費就打發了。反過來，服是 24 小時不間斷有人、CPU 長期高負載，動態計費累積起來會比固定計費貴，老實選固定。

## NAT 共享 IP，和那個 150 元/月的獨立 IP

表格裡標「NAT」的機器是共享 IP 方案：不給你獨立公網 IP，改成分配一批連接埠讓你用。面板服就是這種，固定給 10 個連接埠。好處是便宜，缺點是朋友連進來要帶上連接埠號，而且不適合拿去對外打廣告。

需要獨立公網 IP 直連的話，另外加價，**150 元/月/個**。這個數字很容易被忽略，因為它不在套餐價裡，是加購項。

判斷標準：三五個朋友自己玩，NAT 完全夠用，把 IP 和連接埠發到群裡就行。要開社群服、去論壇或 Discord 拉陌生人進來，建議直接上獨立 IP，少一堆連不上線的溝通成本。以寧波 2 核 4G 那台算，130 元月租加 150 元獨立 IP，實際支出接近翻倍，這筆錢要提前算進預算。
